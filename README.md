B. Informasi Aplikasi

Nama Aplikasi : QuizVerse

Deskripsi Singkat : 

QuizVerse adalah aplikasi kuis pilihan ganda berbasis Flutter yang memungkinkan pengguna mengerjakan soal, memilih jawaban, melihat progress quiz, memperoleh hasil secara otomatis, dan melakukan review terhadap jawaban yang telah diberikan.

Aplikasi ini dibuat sebagai proyek UTS Lab Pemrograman Mobile.

Fitur-Fitur

- Input nama pengguna
- Validasi nama
- Quiz pilihan ganda
- Progress quiz
- Pilihan jawaban
- Tombol Next dan Previous
- Penyimpanan jawaban selama quiz
- Perhitungan skor otomatis
- Persentase hasil quiz
- Review jawaban
- Status jawaban benar atau salah
- Ulangi quiz
- Kembali ke halaman utama
- Light Mode
- Dark Mode
- Responsive UI
